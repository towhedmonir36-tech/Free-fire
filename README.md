# Last Drop — Battle Royale

A lightweight, original, mobile-friendly browser battle royale prototype.

## Play

1. Open [index.html](./index.html) in a modern browser, or enable GitHub Pages to host it.
2. Tap **DEPLOY**.
3. On mobile, use the left joystick to move. Tap **AIM** to toggle aim assist, hold **FIRE** to shoot, and tap **RELOAD** when needed.
4. Walk over green medical supplies or yellow ammo pickups to collect them.
5. Stay inside the blue safe zone and survive the enemy bots.

## Desktop controls

- **WASD / Arrow keys** — move
- **Mouse click** — aim and fire
- **Space** — fire
- **R** — reload

## Files

- `index.html` — complete game (HTML, CSS and JavaScript in one file)

## Hosting with GitHub Pages

1. Open the repository **Settings**.
2. Choose **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After deployment finishes, open the Pages URL shown there.

This is an original single-player prototype with bot opponents. It is not the official Garena Free Fire game and does not include online multiplayer or official game assets.
